# 示例课程文章

> 这是一篇示例文章。你可以把本文当作模板，照着它的格式写你自己的文章。

## 一、这是二级标题

正文写在这里。在 Markdown 里，**两个星号**包起来表示「加粗」，*一个星号*表示「斜体」。

## 二、列表

### 无序列表

- 第一点
- 第二点
- 第三点

### 有序列表

1. 第一步
2. 第二步
3. 第三步

## 三、代码

行内代码用一对反引号包起来，比如 `print("hello")`。

代码块用三对反引号，并写上语言名字：

```python
def hello():
    print("你好，世界")
```

## 四、链接和图片

- 链接：[点击访问](https://www.example.com)
- 图片：`![图片说明](图片地址)`

## 五、表格

| 列一 | 列二 | 列三 |

| 内容 | 内容 | 内容 |
| 内容 | 内容 | 内容 |

以上就是一篇示例文章的常见写法。记住几个要点：

- 文章开头用 `# 标题`（一级标题）
- 分节用 `## 二级标题`
- 正文直接写，需要强调的地方就用「加粗」或「引用」
